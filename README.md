# App Parking

Marketplace de parking privado por horas, con seguridad como eje del producto.

## Estado
Staging funcional en VPS con:
- app conductor responsive
- backend FastAPI + SQLite
- reservas, favoritos, check-in/check-out
- seguridad por niveles A/B/C
- panel Partner/inmobiliaria
- documentación de producto, seguridad, captación y lanzamiento

## Principio de producto
Oferta antes que demanda. App Parking se plantea como una red neutral de parking privado, con inmobiliarias y propietarios como canal de oferta.

## Desarrollo
La fuente de verdad de código y documentación será este repositorio.
